# Machine Learning Foundations and Algorithms

This repository presents a structured and academically grounded study of
**classical Machine Learning**, covering data analysis, preprocessing,
supervised and unsupervised learning, regularization, ensemble methods,
optimization techniques, and model evaluation.

The project emphasizes **conceptual clarity, algorithmic understanding,
and methodological correctness**, making it suitable for
**scholarship evaluation, European MSc programs, US PhD applications,
and technical interviews**.

---

## Repository Structure

- **01_Foundations**  
  Machine Learning overview, NumPy, and Pandas

- **02_Data_Analysis**  
  Exploratory Data Analysis (univariate and multivariate)

- **03_Data_Preprocessing**  
  Missing value handling, outlier detection, scaling, and encoding

- **04_Feature_Engineering**  
  Feature construction, splitting, and transformations

- **05_Dimensionality_Reduction**  
  Principal Component Analysis (PCA)

- **06_Supervised_Learning**  
  Regression and classification algorithms

- **07_Unsupervised_Learning**  
  Clustering algorithms (K-Means, Agglomerative)

- **08_Model_Evaluation**  
  Regression and classification metrics

- **09_Optimization**  
  Gradient-based optimization techniques

- **10_Regularization**  
  Ridge, Lasso, and Elastic Net

- **11_Ensemble_Learning**  
  Voting, Bagging, Random Forest, Boosting, Stacking, and Blending

- **12_Datasets**  
  Datasets used across experiments
